# Abaddon Agent 2: HL2 source + обязательная синхронизация (23.11.2026)

Это не новая игра, а полный пакет передачи для агента. Включены **предыдущие 21 Markdown**, реальные исходники и карта HL2 flight lab из ветки native-flight, реакторные исходники этой же линии, обе стороны дельт после общей базы, три версии каждого пересекающегося файла, проверка пробного Git merge и неразрушающий worktree-скрипт.

Основной игровой commit: d9cf3c15e3f9fdeaa1c3e608eaa2a3f21791697d. Native+reactor: 5849463a3d3417a16d3cb98e32f8b13e83557bb9. Общая база: 6cb7848069c6422632672f626a1346532dfa942e.

Первым прочесть 00_SYNC_FIRST_RU.md, затем 02_SYNC_CONTRACT_RU.md, 01_NATIVE_HL2_STATUS_RU.md и оригинальный handoff.

**Внимание:** пользовательская локальная ветка второго агента не получена. Скрипт позволяет безопасно синхронизировать её на его машине после фиксации его изменений, не уничтожая её. Наличие C++ патча и BSP не означает наличие готовых Windows DLL или полноценного боевого HL2 порта. Нельзя просто заменить main содержимым native-flight.
