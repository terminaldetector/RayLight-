# Abaddon: передача второму агенту с обязательной синхронизацией

Версия передачи 23.11.2026. Этот пакет ДОПОЛНЯЕТ прежние 21 Markdown-файл, а не заменяет их. ВАЖНО: старая рекомендация начать с чистой ветки больше НЕ подходит агенту, который уже сделал свои правки.

## Порядок работы

1. Прочитать 02_SYNC_CONTRACT_RU.md.
2. Затем ORIGINAL_HANDOFF/00_START_HERE_RU.md и остальные разделы по моделям, меню, AI, рендеру и лаунчеру.
3. Прочитать 01_NATIVE_HL2_STATUS_RU.md, открыть реальные файлы HL2_NATIVE_PORT/DRMD-6DOF/native/hl2.
4. Посмотреть SYNC_REPORT.json и MERGE_PREVIEW.json, а также версии спорных файлов в THREE_WAY/BASE, MAIN и NATIVE.
5. Сохранить СВОИ локальные изменения второму агенту, выполнить неразрушающую синхронизацию через scripts/sync_agent_worktree.py.

## Фактическое содержимое архива

- ORIGINAL_HANDOFF: все 21 MD и индекс моделей из предыдущего handoff.
- HL2_NATIVE_PORT: настоящие файлы C++ SDK overlay, патч, скрипт установки, BSP/VMF flightlab, тесты, лицензии, журнал сборки из native-flight.
- BRANCH_DELTAS/MAIN и BRANCH_DELTAS/NATIVE: реальные версии ВСЕХ файлов, изменённых в соответствующей ветке с момента общей базы. Вторая содержит также reactor изменения.
- THREE_WAY: тройки файлов из общей базы, main и native для пересечений.
- scripts/sync_agent_worktree.py: неразрушающий способ создать интеграционную копию из собственной ветки агента.
- SYNC_REPORT.json, MERGE_PREVIEW.json, CONTENTS_SHA256.txt: происхождение, статус пробного слияния и контрольные суммы.

Этот ZIP НЕ заменяет полный Windows release: неизменённые игровые ассеты брать в закреплённом main и полном ZIP.

## Директива

Агент обязан сохранить свои старые исходники и C++ HL2-порт, интегрировать их с последними игровыми изменениями без удаления реактора, оружейных фабрик, NPC, моделей, саппортов и Q-menu. Никаких force-push main, reset --hard или выбора стороны whole-file в конфликте. Выдать результат как код/PR с реальными проверками, а не как ещё один длинный аудит.
