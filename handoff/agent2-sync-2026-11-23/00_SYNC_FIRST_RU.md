# Half-Life: Abaddon — обязательная синхронизация второго агента

**Срез от 23.11.2026.** Этот пакет дополняет предыдущие **21 Markdown-файл** и включает **реальные файлы** native HL2, а не только ссылки на ветку.

## Важнейшее условие

Прежде чем что-либо переносить, второй агент **сохраняет свою рабочую ветку**: опубликованные и локальные коммиты, staged/unstaged файлы, untracked модели, DLL, конфигурации и SDK overlay. Запрещены `reset --hard`, `clean -fd`, слепое копирование нового архива поверх его worktree и массовое разрешение конфликтов `--ours/--theirs`.

**Работа второго агента, отсутствующая на GitHub, мне недоступна.** Поэтому собранный пакет не является доказательством слияния неизвестных локальных правок. До реального трёхстороннего merge статус `SYNC_PENDING_AGENT_WORKTREE`.

## Содержимое нового архива

- `CONTEXT_21_MD/`: полностью сохранён старый архив MD (модели, сокеты, материалы, мобов/саппортов, launcher, карты, тесты и индексы).
- `HL2_NATIVE_PORT_SOURCE.zip`: реальная папка `DRMD-6DOF/native/hl2/` и нужные генераторы Flight Lab. Патч Source SDK, C++ headers, setup, VMF/BSP, тесты, build log, лицензии.
- `REACTOR_BRANCH_CHANGED_FILES.zip`: реальные изменённые файлы из Reactor относительно `6cb7848` (Lua, VMF/BSP, модели и документация), **не** overwrite-пакет.
- `BRANCH_OVERLAPS.json`, `MERGE_OVERLAPS_RU.md`, `GIT_MERGE_PREVIEW.txt`: конфликтная карта между закреплёнными исходниками без изменения Git-веток.
- `SOURCE_PROVENANCE.json`, `SHA256SUMS.txt`: происхождение и целостность.
- `07_HL2_PORT_AND_REACTOR_RU.md`, `SYNC_WORKTREE_CHECKLIST_RU.md`: установка и протокол согласования.

## Обязательный порядок

1. Сохранить **собственный** рабочий код второго агента.
2. Выбрать его реальную ветку как старт интеграционного worktree, синхронизировать сначала `main`, потом `native-flight`. **Не** вливать Reactor второй раз: он предок native.
3. Объединить конфликтующие AI, меню, mission, model/socket, визуальное оружие и реакторную VMF по смыслу, не выбирать версию по более свежей дате.
4. Испытать затронутые GMod фичи и отдельный native C++ Flight Lab. Отличать unit/build от живого клиента.
5. Сделать один интеграционный PR и `SYNC_RESULT_RU.md`: сохранённый SHA исходного агента, входные SHA и фактические тесты. `SYNC_DONE` только после сравнения собственных изменений.

Полноценный HL2-порт ещё **не готов**. Windows launcher пока запускает `hl2-content` без GLua gameplay. Цель проекта — **один Abaddon, два полноценных runtime с согласованными механиками**, а не два независимых мода. Нельзя подмешивать сюда Minecraft Ungravity.
