# SYNC CONTRACT: нельзя уничтожать работу второго агента

## До любых merge

Агент проверяет git status --short, git branch -vv, git log -8 --oneline --decorate, git remote -v. Сохраняет свои изменённые файлы/коммиты на своей ветке, **не публикуя секреты, билды Valve или случайные файлы**. Нельзя делать git reset --hard, git clean -fdx, force-push, общий ours/theirs.

Публичный репозиторий не содержит явно указанной отдельной ветки этого агента. Если у него есть собственные локальные изменения, без предоставления их нельзя считать синхронизацию завершённой.

## Безопасный путь

    python3 scripts/sync_agent_worktree.py --repo /path/to/RayLight --out /path/to/RayLight-agent2-sync

Скрипт работает только при чистой исходной рабочей копии и создаёт новый Git worktree от текущего HEAD агента. В новом worktree сначала выполняется merge pinned main, потом merge pinned native. Оба шага сохраняют историю; в конфликте скрипт останавливается без выбора стороны. Исходная папка агента остаётся неизменной.

При первом конфликте: исправить файлы в созданном worktree, git add, git commit, затем выполнить merge native вручную. При конфликте второго: аналогично. Когда Git автоматически соединил текст, проверить смысловые изменения всё равно обязательно.

## Что сохранить

- GMod прямой spawn: 12 типов оружия, 24 юнита, 5 саппортов, реальные иконки/превью, Undo/лимиты, серверная экономика.
- 6DOF, четыре сокета (верх, низ, бока), мина отдельно, BFG/rail/gravrail/крюк/порталы, ширина боковых пушек 1.125 (ползунок) и скрываемая камера Forsaken.
- Поведение 3 слотов/5 Granada-саппортов, ограниченный ресурс, самостоятельные AI циклы в работе.
- Reactors: критические стадии, coolant, новая шахта и маршруты с отдельными картами; не потерять тесты.
- Арт: 79 Source MDL-комплектов, VMT, привязки socket/muzzle, procedural-пять саппортов и рендер.
- HL2 C++: патч и общая математика SDK 2013 SP, не ломать сборку.
- Один Windows launcher, разные режимы gmod / hl2-content / будущий hl2-native.

Нельзя смешивать с Minecraft Ungravity или объявлять PBR готовым: Shader UnlitGeneric и аренам без отражений требуется отдельная работа.

## Приёмка

Один новый PR с merge commit и короткой матрицей: исходный HEAD агента, main SHA, native SHA, разрешённые конфликты, сохранённые файлы, перечень изменённых игровых контрактов, минимально необходимые тесты. GMod-client и HL2-native-client обозначить PASS/FAIL/NOT_RUN. Headless PASS не означает игровой запуск. Никаких повторных бюрократических аудитов вместо кода.
