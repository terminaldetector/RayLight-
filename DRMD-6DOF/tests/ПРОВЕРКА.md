# Повторение облачных тестов

1. На выделенном сервере Garry’s Mod x64 установите оба аддона из архива.
2. Для прогона добавьте отдельный временный аддон с файлом `lua/autorun/server/drmd_cloud_verify.lua`.
3. Запустите чистый локальный сервер Sandbox на `gm_flatgrass`. Установите `sv_hibernate_think 1`, чтобы таймеры тестов шли до подключения игрока, и `d6_profile auto`. Тест проверит загрузку всех 79 MDL, полёт, вооружение, рой, новый элитный класс и два исхода забега. В конце он переключит профиль на `campaign`.
4. Для прогона эпизода положите рядом `drmd_episode_verify.lua`. Перезапустите сервер на `d6_city17_drain` с `d6_profile auto`. Испытание войдёт в триггеры города, загрузит реактор и пройдёт проверку ядра и выхода. Для отдельной проверки реактора запустите `d6_reactor_escape` напрямую.
5. Ищите строки `[DRMD QA]`, `[DRMD MAP QA]` и маркеры `COMPLETE`. По завершении удалите тестовый аддон и верните желаемый профиль. Используйте отдельный тестовый сервер.

Для проверки сеток запустите `texlua export_art.lua` из этой папки. Для проверки отрисовки и выбора секций запустите `texlua replay_ui.lua 1600 900 hangar`. Доступны также сценарии `cockpit`, `beam`, `flight`, `campaign`, `episode` и `rogue`. Сценарии используют команды отрисовки аддона и тестовые состояния. Проверка графического клиента и оригинальных карт Half-Life 2 проводится отдельно. [Журнал облачной проверки](RESULTS.txt)
