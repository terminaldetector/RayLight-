# Half-Life: Abaddon — Windows Launcher

## Запуск готового пакета

1. Распакуйте **весь** Windows-архив Abaddon в обычную папку.
2. Откройте `AbaddonLauncher.exe`. Установка Python, Go, .NET или Git не требуется.
3. Выберите **Garry’s Mod — игровая сборка** либо **Half-Life 2 — карты и модели**. Лаунчер ищет Steam, дополнительные библиотеки и установленные игры. При необходимости выберите папку вручную или вставьте путь к игре/её EXE.
4. Выберите стартовую карту, разрешение, оконный режим и профиль графики.
5. Нажмите **«Установить и запустить»**. Steam должен иметь доступ к выбранной установленной игре. Лаунчер не скачивает и не заменяет клиент игры.

Системные требования лаунчера: **64-битная Windows 10/11**. Права администратора не запрашиваются. Папка установки игры должна быть доступна для записи текущему пользователю.

**GMod:** полёт 6DOF, боевое ядро PR #1, мины, ангар, прогрессия и три слота / пять типов саппортов Granada из PR #2. Основная арена — `d6_relay_vault`, сюжет проходит через `d6_city17_drain` и `d6_reactor_escape`. Для режима roguelike доступен старт на `d6_rogue_reactor`.

**Half-Life 2 — карты и модели.** Лаунчер устанавливает `maps`, `models` и `materials` для просмотра в штатном Half-Life 2 (Steam App 220).

**HL2 · Flight Lab (эксперимент).** Выберите зарегистрированный в Steam Source SDK Base 2013 Singleplayer (App 243730) и отдельно собранный мод `abaddon_native`. Лаунчер ищет мод в `steamapps/sourcemods` и принимает ручной путь. Кнопка «Запустить» становится доступной после проверки `gameinfo.txt`, библиотек `bin/client.dll` и `bin/server.dll` сборки Flight Lab для Win32 и `maps/d6_native_flightlab.bsp`. Для сборки используйте исходники и инструкцию `DRMD-6DOF/native/hl2/README.md`. Windows-библиотеки Flight Lab требуют отдельной сборки из Source SDK.

## Что делают кнопки

| Кнопка | Действие |
|---|---|
| Найти игры | Повторно прочитать Steam и его библиотеки. |
| Обзор | Выбрать папку игры; поле также принимает ручной путь. |
| Установить и запустить | Проверить файлы пакета по SHA-256, установить выбранный target, передать команду запуска клиенту. |
| Только установить | Установить/обновить аддон или HL2-контент без запуска. |
| Запустить | Запустить уже установленную копию с выбранными параметрами. |
| Откатить установку | Вернуть предыдущую установленную копию; текущая сохраняется в резерве. |
| Папка игры | Открыть подтверждённую папку контента выбранного клиента. |
| Диагностика | Показать локальный build/target/manifest и ограничения возможностей. |

При нескольких найденных установках доступны пути в выпадающем списке. Лаунчер запоминает пути, стартовую карту, графику, разрешение и состояние консоли независимо для каждого клиента. Перед обновлением или откатом закройте игровой клиент.

## Установка и данные

Для GMod используется `<GarrysMod>/garrysmod/addons/descent_scanner`, для HL2 — `<Half-Life 2>/hl2/custom/drmd`. Стадия установки и резервные копии находятся в `abaddon-launcher-state` внутри папки игрового контента, **вне** `addons` и `custom`, чтобы Source не монтировал вторую копию.

Файлы проверяются до смены установленной версии. При штатной ошибке commit-стадии предыдущая копия восстанавливается. Нефиксированные в предыдущем манифесте пользовательские файлы сохраняются; устаревшие файлы самой поставки учитываются отдельно. Лаунчер не удаляет чужие аддоны, сохранения, бинды или `autoexec.cfg`.

Если прежний аддон установлен как GMA/Workshop-пакет или в другой папке, отключите эту копию перед запуском: лаунчер не управляет сторонними подписками. Не держите две активные копии Abaddon.

`swep_construction_kit` входит в полный пакет как необязательный редактор оружия. Он не устанавливается автоматически. При необходимости скопируйте его рядом с аддоном, если такого редактора ещё нет.

Настройки и локальный журнал лаунчера: `%LOCALAPPDATA%\AbaddonLauncher`. Журнал может содержать локальные пути. Ничего не отправляется по сети; обновление игры поставляется новым полным ZIP.

## Тени, материалы и PBR

По умолчанию выбраны **«Настройки игры — не менять»**. Явный выбор «Сбалансированный» или «Высокий» создаёт только отдельный `cfg/abaddon_launcher.cfg`, выполняемый через `+exec` при запуске.

| Параметр | Сбалансированный | Высокий |
|---|---:|---:|
| Штатные тени / render-to-texture | Включены | Включены |
| Тени фонарика | Включены | Включены |
| Shadow depth texture | 1024 | 2048 |
| Anisotropic filtering | 8× | 16× |
| Bump/specular материалов, которые их поддерживают | Включены | Включены |

Движок может сохранить значения некоторых графических ConVar при выходе. «Настройки игры — не менять» означает не применять профиль при следующем запуске; это **не автоматический возврат** прежних значений. Откат установки возвращает payload, а не персональные настройки графики.

**Полноценного PBR в этой сборке нет.** Профили не добавляют отсутствующие normal/roughness/metalness-карты, отражения или источники света. Процедурные корпуса используют упрощённое освещение `UnlitGeneric`; карты собраны с LDR-освещением без локальных cubemap samples. Соответствие реальных теней видимым процедурным корпусам требует отдельного игрового прогона. Подробные причины и задачи — в `DRMD-6DOF/WINDOWS_LAUNCHER_HANDOFF_RU.md`.

## Разработчику

Исходники лаунчера — `DRMD-6DOF/launcher`. Используется Go standard library и Win32 API; внешних Go-модулей нет. Игровая логика остаётся в аддоне.

```sh
cd DRMD-6DOF/launcher
go test ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -ldflags="-H=windowsgui -s -w" -o AbaddonLauncher.exe .
```

В Windows PowerShell переменные задаются через `$env:GOOS='windows'` и `$env:GOARCH='amd64'`; на Windows эти значения уже соответствуют host. Воспроизводимая упаковка из корня репозитория:

```sh
python3 DRMD-6DOF/tools/package_windows.py --go /path/to/go --out /path/to/output
```

Скрипт упаковывает текущий чистый Git HEAD, создаёт manifest с полной revision и проверяет наличие всех указанных payload-файлов. `AbaddonLauncher.exe --smoke-ui` открывает окно, проверяет создание контролов и закрывает его без установки/запуска игры; режим предназначен для Windows CI.

Проверки ядра установки и Win32 UI не заменяют запуск лицензированного GMod/HL2 и проверку сцены в графическом клиенте. Точный состав поставки задаётся `abaddon-build.json`; предыдущие снимки/превью в `captures` не являются новыми кадрами данной сборки.
