# Half-Life: Abaddon · Windows-лаунчер

Откройте `Abaddon.exe`, выберите среду и нажмите **Запустить**. Лаунчер читает список библиотек Steam и манифесты игр. Пустое поле использует автопоиск, введённый путь становится ручным выбором. Для каждого профиля сохраняются карта, режим экрана, разрешение и флаги консоли, заставки и журнала. Файл настроек находится в `%LOCALAPPDATA%/HalfLifeAbaddon/launcher.json`.

| Профиль | Что запускает |
|---|---|
| Garry’s Mod | Steam App 4000 с аддоном `descent_scanner`. Включает четыре карты Abaddon, боевые сценарии и roguelike. Режим аддона применяется через отдельный конфиг локальной игры в `garrysmod/cfg/`. |
| HL2 · карты | Steam App 220 с картами, моделями и материалами в `hl2/custom/abaddon_content`. Сценарии используют штатные сущности Half-Life 2. Статус сборки — `content-only`. |
| HL2 · Flight Lab | Steam App 243730 с отдельным экспериментальным полигоном 6DOF. Лаунчер проверяет полигон и собранные под Win32 библиотеки `client.dll` и `server.dll` в папке нативного мода. Графический прогон этого профиля требует Windows-сборки SDK Base. |

## Установка и обновление пакета

Положите `Abaddon-Game.zip` рядом с EXE или выберите папку, где он сохранён. В профиле Garry’s Mod или HL2 · карты нажмите **Установить пакет** и подтвердите режим. Пакет содержит одну сборку канала `dev` из коммита `5849463a3d3417a16d3cb98e32f8b13e83557bb9`. Её статус и ревизия берутся из `manifest.json`.

Лаунчер сверяет хеши и распаковывает файлы во временную папку. При обновлении предыдущая версия попадает в резервную копию в `abaddon_launcher` внутри каталога игры. Кнопка отката возвращает предыдущий пакет. Игровые сохранения, бинды и пользовательские данные находятся в отдельных каталогах игры. Если тот же мод уже смонтирован из другой папки, в окне можно запустить найденный комплект.

## Сборка

Потребуется Go 1.23 или новее. Из каталога `launcher` на Linux или macOS:

```sh
go test ./...
GOOS=windows GOARCH=amd64 CGO_ENABLED=0 go build -trimpath -buildvcs=false \
  -ldflags '-H windowsgui -s -w' -o Abaddon.exe .
python3 tools/build_bundle.py Abaddon-Game.zip
```

В Windows PowerShell:

```powershell
$env:CGO_ENABLED = "0"
go build -trimpath -buildvcs=false -ldflags "-H windowsgui -s -w" -o Abaddon.exe .
```
