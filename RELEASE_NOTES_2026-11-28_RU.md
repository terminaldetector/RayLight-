# Abaddon — объединённая версия 28.11.2026

**Исходник игры:** `b71e658e5ea6f5d755f7520e3d5cadfe7e834eb6`. PR #3–8 объединены. Коды GMod и HL2 Flight Lab находятся в одном репозитории и сохранены в этой сборке.

**Файлы релиза:**

- `Half-Life-Abaddon-Full-Windows.zip` — полный проект с GMod аддоном, исходниками/моделями, Go/Win32 launcher, optional SCK и C++ overlay для Source SDK.
- `Abaddon-Native-FlightLab-Win32.zip` — **экспериментальный** мод с 32-битными client.dll/server.dll, собранный в CI 46018487410. Используется только после проверки, что его native-исходники совпадают с merged main.
- `ABADDON_MASTER_TZ_RU.md` — полное техническое задание и готовая дорожная карта.
- `INTEGRATION_STATUS_2026-11-28_RU.md` и `SHA256SUMS-MERGED.txt` — отчёт о слиянии и контрольные суммы.

**Запуск:** распаковать полный ZIP, запустить `AbaddonLauncher.exe` и выбрать GMod. HL2-content устанавливает только карты/модели. Для Native Flight Lab нужен Steam **Source SDK Base 2013 Singleplayer (App 243730)** и соответствующий экспериментальный mod.

**Ограничение:** native Flight Lab пока не является полным портом игрового процесса GMod и **не проверен в живом лицензированном клиенте HL2**. Сборка Win32 DLL, static/unit tests и проверки выделенного сервера не равны реальному игровому прогону. Лаунчер x64 и game DLL Win32 имеют правильную разную архитектуру.

Этот релиз заменяет по актуальности Windows-пакет от 22 ноября; исходный старый релиз сохранён для истории.
